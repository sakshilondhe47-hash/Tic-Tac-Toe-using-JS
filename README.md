# 🎮 Tic-Tac-Toe Game (JavaScript)

A browser-based Tic-Tac-Toe game built using core JavaScript concepts like DOM manipulation, arrays, and modern ES6 functions. This project focuses on implementing game logic from scratch without using any external libraries or frameworks.

---

## 🚀 Features

* 👥 Two-player gameplay (Player X vs Player O)
* 🧠 Winning logic using arrays
* 🔄 Game reset functionality
* ⚡ Real-time UI updates using DOM manipulation
* 🧩 Clean and minimal user interface

---

## 🛠️ Tech Stack

* **HTML** – Structure
* **CSS** – Styling & layout
* **JavaScript** – Game logic

---

## 💡 Concepts Used

* DOM Manipulation
* Arrays & indexing
* Arrow functions
* Conditional statements
* Event handling

---

## 📂 Project Structure

```bash
tic-tac-toe/
│
├── index.html     # Game layout
├── style.css      # Styling
└── first.js       # Game logic
```
